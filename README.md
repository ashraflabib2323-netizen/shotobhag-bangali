# শতভাগ বাঙালি — MVP

## চালানোর নিয়ম

1. Node.js 20+ ইনস্টল করুন।
2. এই ফোল্ডারে terminal খুলুন।
3. চালান:

```bash
npm install
npm run dev
```

তারপর `http://localhost:3000` খুলুন।

## MVP-তে যা আছে

- Home screen
- ছেলে/মেয়ে/বাচ্চা/সবার জন্য profile selection
- নাম দেওয়ার ব্যবস্থা
- category-by-category quiz
- ছবি-ভিত্তিক item button
- selected হলে ছবির ওপর সাদা translucent overlay
- live selection count
- percentage result
- category-wise score
- PNG result-card download
- Web Share API
- mobile-first responsive design
